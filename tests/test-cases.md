# PP-food-KV-001 Regression Tests

这些测试来自真实失败模式。任何版本升级都必须避免回归。

## Test 01｜Food DNA 必须先锁住

输入：青椒酸菜鱼随手拍 + 主标题/副标题/地址/电话。

PASS：鱼片、青红椒圈、青花椒、汤色、红色器皿、摆盘拓扑与原图高度一致；先像同一份菜的电影级商拍，再进入 KV。

FAIL：为了视觉张力重新生成更多鱼片、改变鱼片形状、增加配料、换器皿、重摆盘。

## Test 02｜KV 不能只是“上字下菜”

PASS：主标题参与空间结构，Hero Food 最近景，存在明确纵深和一处主消失点。

FAIL：标题在顶部平贴，食物在底部，像菜单宣传单。

## Test 03｜主标题空间化

PASS：标题可成为门头、舞台、墙体、门廊或纵深文字场，与环境统一光影。

FAIL：标题只是漂浮在背景上的发光字。

## Test 04｜统一消失点

PASS：标题结构、桌面、器皿、背景建筑和信息模块在同一透视逻辑内。

FAIL：食物、标题、背景各自使用不同透视。

## Test 05｜受控遮挡

PASS：蒸汽或碗沿仅轻擦标题边缘，文字仍 100% 可读。

FAIL：食物或蒸汽吞掉关键笔画；为层次感牺牲可读性。

## Test 06｜餐饮风格防污染

PASS：迁移巨字透视、Hero Product、前中后景等 Campaign 语法，但保持餐饮、地域、菜系语义。

FAIL：出现 HUD、科技通道、赛博霓虹、参数面板、数码发布会视觉。

## Test 07｜信息门槛

主标题 + 副标题 + 至少一个辅助字段才允许设计。

FAIL：只上传照片就直接生成 KV，或编造地址/电话/价格。

## Test 08｜完整信息密度

满足门槛后，默认构建完整 Campaign 信息层：主标题、副标题、Slogan/传播句、3–4 个卖点、已有店名/地址/电话、QR 区域。

FAIL：只有主标题 + 副标题 + 食物，视觉和信息过平；或塞入大量无关小字形成宣传单。

## Test 09｜卖点不得伪造硬事实

PASS：卖点基于用户输入、菜名语义或照片可支持的感官属性，如“鱼片嫩滑”“鲜麻酸香”“热汤入味”。

FAIL：编造“非遗”“百年老店”“有机认证”“每日现杀”等未经提供的事实。

## Test 10｜二维码真实性

PASS：有真实二维码素材则锁定使用；没有真实二维码则只预留 QR safe zone 或生成明确标注为占位符的非交付构图预览。

FAIL：生成看似真实、实际随机不可控的二维码并作为正式交付信息。

## Test 11｜标题准确率

主标题、副标题、地址、电话等用户提供文字必须 100% 准确。

任何错字、漏字、数字错误 → FAIL。

## Test 12｜信息可后续增删改查

默认 Campaign 信息密度不是死模板。用户说“去掉二维码 / 卖点减到 2 个 / 电话换位置 / 主标题改成……”时，仅修改相应层级，不重做食物主体。
