# Typography Personality Map

## Goal

字体不是“统一金色毛笔字”，也不是只给主标题换一个字形。

> **Typography = font personality + spatial medium + material + hierarchy + perspective + category semantics.**

主标题、副标题、Slogan、卖点与品牌信息共同构成完整文字系统，必须服从食品品类、品牌定位与传播语气。

## Mapping

- 中式家常热菜：brush-inspired display / bold Chinese sans / signage style
- 川湘热辣：heavy brush / condensed bold / aggressive display
- 砂锅煲汤：thick carved display / warm serif / plaque typography
- 面食粉类：bold condensed / vertical rhythm / hand-painted shop style
- 烧烤夜市：hand-painted signage / condensed sans / marquee type
- 高档海鲜中餐：refined Song-style / elegant modern sans / restrained metallic display
- 蛋糕甜点：editorial serif / fashion serif / soft display / elegant sans
- 咖啡茶饮：modern grotesk / neo-grotesk / editorial sans / restrained serif
- 西餐：high-contrast serif / fine dining serif / clean grotesk
- 日韩料理：minimal sans / narrow grotesk / restrained East-Asian display
- 烘焙早餐：warm serif / friendly sans / clean sans / subtle handwritten accent
- 包装食品：brand display / clear sans / retail hierarchy

## Gold Brush Rule

金色毛笔字只在菜品语义、品牌定位和空间语言都支持时使用。它是一个选项，不是默认皮肤。

禁止因为上一张中餐 KV 使用成功，就把金色毛笔字、厚重牌匾字或红金系统迁移到烘焙、甜点、咖啡、西餐等品类。

- signage
- architecture
- stage
- depth field
- ribbon / soft sculpture

- menu wall

## Full Text-System Hierarchy

### Headline

- 是第二视觉锚点，产品永远第一；
- 必须使用当前品类允许的字体人格；
- 应具有当前品类合理的材质、厚度、透视、投影、悬挂、附着或空间关系；
- 不允许仅靠“放大 + 加描边”冒充上限设计。

### Subtitle

- 必须明显从属于主标题；
- 不默认与主标题同平面、同横排、同响度；
- 可采用当前品类原生介质：吊牌、包装纸带、玻璃小字、菜单条、墙面小字、标签、丝带等；
- 既要可读，又要参与空间层级。

### Slogan / Selling Points

- 视觉响度低于副标题；
- 使用同一品类系统的辅助字体与材质；
- 不强制圆章、不强制卡片、不强制四宫格；
- 信息模块的造型必须属于当前品类。

### Brand / Utility Information

- 服从品牌识别；
- 清晰、准确、可读；
- 不抢产品与主标题；
- 不把品牌 Logo/店名做成另一套无关视觉皮肤。

## Category-Native Spatial Examples

### BAKERY_BREAKFAST_SYSTEM

推荐：
- warm serif / clean sans / subtle handwritten accent
- 橱窗立体字
- 玻璃门店字
- 包装纸压印字
- 烘焙吊牌
- 晨光投影字
- 轻木牌 / 金属细字

材质：纸、亚麻、玻璃、木、烤盘、麦金、奶油白。

禁止：重黑金江湖毛笔、爆炒式牌匾、饭馆圆章堆叠。

### DESSERT_CAKE_SYSTEM

推荐：editorial serif、fashion serif、柔性展示字、奶油浮雕、丝带、玻璃/亚克力轻装置。

### COFFEE_TEA_SYSTEM

推荐：modern grotesk、editorial sans、玻璃窗面字、透明字、投影字、低密度 lifestyle 排版。

### NOODLE_RICE_NOODLE_SYSTEM

推荐：bold condensed、纵向节奏、手绘店招、上升/通道/蒸汽纵深；但产品仍是第一主角。

## Fail Conditions

以下任意情况视为 Typography System FAIL：

- 主标题字体与当前品类明显错配；
- 主标题有立体感，但副标题/Slogan/辅助文字全部平贴；
- 文字材质与背景材质彼此无关；
- 空间介质不属于当前品类；
- 把上一品类成功的字体皮肤直接复用；
- 主副标题只是三行平行横排；
- 为了标题张力缩小或遮挡 Food Hero；
- 如果把产品换成另一完全不同品类，整套文字系统仍无需变化。
