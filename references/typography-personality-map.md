# Typography Personality Map

## Goal

字体不是“统一金色毛笔字”。字体性格必须服从食品品类、品牌定位与传播语气。

## Mapping

- 中式家常热菜：brush-inspired display / bold Chinese sans / signage style
- 川湘热辣：heavy brush / condensed bold / aggressive display
- 砂锅煲汤：thick carved display / warm serif / plaque typography
- 面食粉类：bold condensed / vertical rhythm / hand-painted shop style
- 烧烤夜市：hand-painted signage / condensed sans / marquee type
- 高档海鲜中餐：refined Song-style / elegant modern sans / restrained metallic display
- 蛋糕甜点：editorial serif / fashion serif / soft display / elegant sans
- 咖啡茶饮：modern grotesk / neo-grotesk / editorial sans / restrained serif
- 西餐：high-contrast serif / fine dining serif / clean grotesk
- 日韩料理：minimal sans / narrow grotesk / restrained East-Asian display
- 烘焙早餐：warm serif / friendly sans / subtle handwritten accent
- 包装食品：brand display / clear sans / retail hierarchy

## Gold Brush Rule

金色毛笔字只在菜品语义、品牌定位和空间语言都支持时使用。它是一个选项，不是默认皮肤。

## Spatial Form Options

- signage
- architecture
- stage
- depth field
- ribbon / soft sculpture
- glass / acrylic plane
- menu wall
- hanging sign
- window typography
- retail display wall

选择空间形态时必须与品类材质一致。
