# Domain Style Firewall

## Transfer Method, Not Industry Skin

可以迁移其他优秀 Campaign 的构图方法：

- Hero Product 最近景
- 巨型文字
- 一点透视 / 斜切透视
- 空间化标题
- 前中后景
- 受控遮挡
- 强负空间
- 信息层级
- 统一光影

但餐饮 KV 默认禁止继承：

- HUD / UI 面板
- 科技参数卡
- 数码功能图标语言
- 赛博霓虹
- 科技走廊
- 未来实验室
- 发光网格
- 产品发布会蓝紫灯

除非用户明确要求品牌使用这些视觉语言。

## Food-native Translation

把“科技舞台”翻译为“餐厅门头 / 店堂 / 石台 / 木构 / 厨房 / 摊位 / 展示空间”；把“参数卡”翻译为克制卖点徽章 / 小料牌 / 菜单信息系统；把“产品英雄”翻译为 Hero Food。

## Rule

任何视觉元素都应回答：它为什么属于这道菜 / 这个餐饮品牌？回答不了就删掉。
