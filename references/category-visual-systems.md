# Category Visual Systems

每个系统定义 7 个维度：字体性格、空间标题、版式倾向、色彩、环境材质、信息密度、禁用风格。

## 1. CN_HOME_STYLE_SYSTEM｜中式家常热菜

适用：小炒、炒肉、家常豆腐、腊肉类、蔬菜热炒。

- mood：烟火气、锅气、真实食欲、朴实高级
- typography：厚重中文展示字、粗黑、适度金色毛笔字
- spatial headline：门头 / 牌匾 / 墙体 / 舞台
- layout：Hero Food 最近景 + 强标题 + 中高信息密度
- palette：暖木、深棕、金、辣椒红/蔬菜绿点缀
- materials：木、黑石、铁锅、餐馆暖灯
- avoid：甜品杂志风、科技蓝、过度极简导致失去烟火气

## 2. SPICY_HOT_SYSTEM｜川湘鲜麻热辣

适用：水煮鱼、毛血旺、青花椒酸菜鱼、麻辣香锅、剁椒类。

- mood：鲜麻、热烈、冲击、热气
- typography：强势粗字 / 厚金毛笔字 / 倾斜透视字
- spatial headline：纵深门头、爆发舞台、透视墙体
- layout：动势强、蒸汽与标题共享空间
- palette：辣椒红、藤椒绿、深木、暖金
- materials：石、木、铜、川味餐馆构件
- avoid：冷白极简、奶油粉、轻奢甜品视觉

## 3. CLAYPOT_SOUP_SYSTEM｜砂锅煲汤热锅

适用：砂锅鸡、海皇粉丝煲、菌汤锅、老鸭煲、酸汤锅。

- mood：温润、浓香、围炉、热雾、厚重丰盛
- typography：厚字体、深刻字、金属/木牌质感
- spatial headline：围锅舞台、汤汽空间、半拱结构
- layout：主体集中，锅体占近景，标题环绕而不压锅
- palette：琥珀、深褐、铜金、食材本色
- materials：陶、砂锅、木台、铜器
- avoid：霓虹、硬科技、过度平面化

## 4. NOODLE_RICE_NOODLE_SYSTEM｜面食米线粉主食

适用：牛肉面、米线、酸辣粉、炒粉、拌面。

- mood：热汤、饱腹、拉力、满足、主食力量
- typography：纵向拉伸、粗黑、毛笔/手写视品类而定
- spatial headline：上升型、通道型、蒸汽纵深型
- layout：面条/米线动线与标题方向呼应
- palette：汤色主导 + 辣红/葱绿/米白
- materials：木桌、瓷器、食堂/面馆空间
- avoid：把所有面食做成统一黑金模板

## 5. BBQ_NIGHTMARKET_SYSTEM｜烧烤炸物夜市

适用：烤串、烧鸟、炸鸡、炸肉、夜市小吃。

- mood：炭火、焦香、夜色、热闹、烟气
- typography：招牌体、手写牌、粗窄黑、少量霓虹仅在真实夜市语义下
- spatial headline：悬挂招牌、摊位门头、灯箱、棚架
- layout：强对角线 / 近景食物 / 烟雾纵深
- palette：炭黑、火橙、暖红、金属灰
- materials：金属、烤架、木签、灯箱
- avoid：精品甜点柔粉、无关赛博 HUD

## 6. SEAFOOD_PREMIUM_SYSTEM｜海鲜高档中餐宴席

适用：清蒸鱼、海鲜煲、鲍汁、海鲜拼盘、高档宴席菜。

- mood：鲜、精致、宴请、克制贵气
- typography：精细宋体/现代黑体/克制金字
- spatial headline：金属牌匾、门厅、精致屏风、轻空间字
- layout：中高留白、秩序感强、信息密度中等
- palette：深蓝灰、玉白、金、海鲜本色
- materials：石材、玉感瓷器、金属、玻璃
- avoid：粗糙江湖大字、夜市杂乱感

## 7. DESSERT_CAKE_SYSTEM｜蛋糕甜点西点

适用：蛋糕、慕斯、泡芙、布丁、甜甜圈、精致西点。

- mood：轻盈、甜美、柔软、精致、仪式感
- typography：editorial serif、优雅无衬线、柔性展示字
- spatial headline：丝带、漂浮舞台、奶油曲面、轻建筑装置
- layout：留白型 / 杂志型 / 局部超大字；信息密度中低
- palette：奶白、柔粉、浅杏、可可、莓果色、低饱和金
- materials：玻璃、亚克力、石英、奶油曲面、丝带
- avoid：中式门头金色毛笔、油烟、重木棕、锅气视觉

## 8. COFFEE_TEA_SYSTEM｜咖啡茶饮饮品

适用：咖啡、拿铁、果茶、奶茶、柠檬茶、特调饮品。

- mood：松弛、城市、生活方式、清爽或香醇
- typography：现代无衬线、杂志字体、极简展示体
- spatial headline：玻璃字、窗面字、桌面投影字、轻量空间字
- layout：留白较多、Lifestyle、品牌感优先；信息密度低到中
- palette：咖啡棕、奶白、清茶绿、柠檬黄、透明高光
- materials：玻璃、金属、咖啡馆木、磨砂亚克力
- avoid：中式大金字门头、家常菜圆章卖点堆叠

## 9. WESTERN_DINING_SYSTEM｜西餐主菜

适用：牛排、意面、焗饭、西式主菜、Fine Dining。

- mood：现代、餐厅仪式感、精致、克制
- typography：高端 serif + clean sans，菜单/杂志式层级
- spatial headline：餐厅墙面、菜单板、建筑字、轻透视展示字
- layout：极简高端、非对称留白、低到中信息密度
- palette：黑白灰、黄油金、酒红、橄榄绿
- materials：石材、银器、皮革、亚麻、玻璃
- avoid：中式牌匾、毛笔门头、川湘爆炒视觉

## 10. JAPANESE_KOREAN_SYSTEM｜日料韩料东亚现代

适用：寿司、刺身、日式定食、拉面、韩式拌饭、韩式炸鸡。

- mood：清洁、结构、克制、年轻、现代东亚
- typography：极简无衬线、窄体、地域感克制字体
- spatial headline：木格、纸面、招帘、简洁门框、标牌
- layout：几何秩序、干净留白、信息密度中低
- palette：原木、白、炭灰、抹茶绿、辣酱红视菜品而定
- materials：木、纸、石、金属、陶器
- avoid：无依据中国传统大金字、景区国潮

## 11. BAKERY_BREAKFAST_SYSTEM｜烘焙早餐

适用：可颂、面包、三明治、早餐拼盘、中西早餐。

- mood：晨间、温暖、香气、轻松、生活方式
- typography：温暖 serif / clean sans / 手写小字
- spatial headline：晨光投影、橱窗字、包装纸字、轻门店标牌
- layout：自然光 editorial、中低信息密度
- palette：奶油白、麦金、烘焙棕、晨光蓝灰
- materials：纸、亚麻、木、玻璃、烤盘
- avoid：重黑金江湖感、强烈爆炒火焰

## 12. RETAIL_PACKAGED_SYSTEM｜零食伴手礼包装食品

适用：卤味包装、礼盒、预包装零食、伴手礼、熟食商品。

- mood：品牌化、商品化、货架识别、购买转化
- typography：品牌展示体 + 清晰卖点字
- spatial headline：包装结构、货架墙、产品阵列、展台
- layout：Hero Packshot + 卖点模块 + 价格/QR/渠道信息；信息密度中高
- palette：服从包装品牌色
- materials：包装材质、纸盒、塑封、金属罐、货架
- avoid：改变包装文字/Logo/结构；不要把商品做成餐馆堂食图

## Selection Rule

系统只能选择一个主视觉系统，最多叠加一个弱辅助系统。辅助系统权重建议 <=30%。禁止 3 个以上系统混搭。
