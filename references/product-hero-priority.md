# Product Hero Priority Rule

这是所有美食品类通用的全局硬规则，优先级高于任何字体、版式和视觉特效偏好。

## 1. 主产品绝对优先

在任何餐饮 / 甜品 / 饮品 / 西餐 / 烘焙 / 包装食品 KV 中，主产品必须始终是第一视觉主角。

不得为了增强主标题、副标题、Slogan、卖点、二维码或装饰图形的存在感，而把主产品压缩成背景、摆设、装饰物或次要元素。

所有文字、空间结构、材质、背景和信息模块都必须围绕产品展开，并服务于产品传播。

## 2. Typography Must Support, Not Overpower

主标题、副标题和 Slogan 可以有：
- 透视
- 厚度
- 材质
- 光影
- 空间感
- 设计张力

但不得取代产品成为第一视觉中心。

文字应该强化产品记忆，而不是让用户先记住字、后发现产品。

## 3. 视觉优先级

默认优先级：

1. PRODUCT / FOOD HERO
2. HEADLINE
3. SPATIAL CONCEPT
4. SUBTITLE
5. SLOGAN / SELLING POINTS
6. ADDRESS / PHONE / QR / UTILITY INFO

不同品类允许改变具体版式，但不得颠倒 1 和 2 的主从关系。

## 4. 产品面积与视觉权重

不以机械百分比作为唯一标准，但必须满足：
- 产品处于视觉焦点或关键黄金区域；
- 产品拥有足够可辨识面积；
- 产品材质、食欲、包装、形态能被第一时间读取；
- 不因大标题而被迫缩小到边角；
- 不因装饰性空间字而退到远景。

## 5. 各品类执行示例

### 中式热菜
标题可以是大字、门头、牌匾，但菜仍必须最近、最大、最有食欲。

### 蛋糕 / 甜点
可以做高级 serif、丝带、柔性空间字，但蛋糕不能变成大片留白中的小摆件。

### 咖啡 / 饮品
可以 lifestyle、杂志化，但杯体、液体层次、冰块、奶泡仍需第一眼可见。

### 西餐
可以 fine-dining editorial，但牛排 / 意面 / 主盘仍然是第一主角。

### 包装食品
可以有强品牌字和卖点系统，但包装本体必须比标题更有购买驱动力。

## 6. Mandatory Fail

出现以下任意情况直接 FAIL：
- 标题比产品更像主角；
- 产品被缩成角落摆件；
- 产品只是为标题提供背景；
- 产品主体被空间字 / 装饰结构大面积压住；
- 用户第一眼主要看到字和装饰，产品识别明显滞后；
- 为了标题张力改变产品原始形态、摆盘或包装结构。

## 7. QA 问题

最终交付前必须问：

1. 去掉文字后，这个产品本身是否仍然成立为强商拍主视觉？
2. 第一眼最先被感知的是产品，还是标题？
3. 标题是否在服务产品，而不是利用产品当背景？
4. 如果缩小产品 20%，画面会不会“更像设计海报”？如果会，说明当前设计可能已经过度文字化。
5. Product Hero 是否仍是整个 KV 的视觉锚点？

## Core Command

> **THE PRODUCT IS THE HERO. TYPOGRAPHY BUILDS THE WORLD AROUND IT.**
>
> **标题可以强，但产品必须更强。**
