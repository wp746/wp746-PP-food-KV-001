# Typography System

## Accuracy First

以下文字必须 100% 准确：主标题、副标题、店名、地址、电话、价格、活动信息。

任何错字、漏字、数字错误、乱码 → FAIL。

## Hierarchy

```text
T1 Headline        100%
T2 Subtitle         35–50%
T3 Slogan/Selling   15–25%
T4 Utility           8–15%
```

## Headline Length

- 2–4 字：适合巨型空间字。
- 5–8 字：适合强标题 / 门头 / 舞台。
- 9–14 字：传播句型，降低空间夸张程度。
- >14 字：不强行巨字化，应使用编辑式排版。

## Typeface Personality

不要所有中餐都使用毛笔字。

- 川味 / 烧烤 / 强刺激：粗黑、窄黑、现代书写性 Display。
- 地域传统菜：现代黑体 + 克制传统字形；必要时毛笔主标题。
- 粤菜 / 日料 / 高端甜点：宋体、编辑衬线、克制黑体。
- 咖啡 / 烘焙：Editorial Serif + Clean Sans。

## Utility Info

地址 / 电话等必须干净、可读，适合放在下角、侧边、自然负空间或与场景透视一致的小信息模块；不要用厚底栏切断画面。

## Chinese Safety

空间化、透视、材质化不能破坏汉字结构。标题可有艺术笔触，但必须优先可读。
