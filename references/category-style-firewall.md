# Category Style Firewall

## Principle

不同美食品类不能共享同一套视觉皮肤。迁移的是 KV 方法论，不是某一品类的字体、材质、场景和信息模块模板。

> **Transfer the method, never the previous category skin.**

## Cross-Job Isolation

每一个新食品任务都必须重新路由当前品类视觉系统。

上一任务 / 上一品类成功使用过的以下元素默认全部失效，除非当前品类规则再次明确支持：

- 字体人格
- 标题材质
- 空间介质
- 场景皮肤
- 配色模板
- 道具模板
- 卖点徽章模板
- 门头 / 牌匾 / 橱窗 / 丝带 / 灯箱 / 菜单墙等具体造型

禁止因为上一张“效果好”就在下一品类继续复用。

## Hard Blocks

### Dessert / Cake
禁止默认使用：中式金色毛笔门头、油烟、深木江湖风、爆炒火焰、密集圆章卖点。

### Bakery / Breakfast
禁止默认使用：重黑金江湖感、川湘毛笔门头、爆炒火焰、密集餐馆圆章、厚重中式牌匾体系。
应优先：晨光、橱窗、包装纸、轻门店标牌、warm serif / clean sans / subtle handwritten accent、纸/亚麻/玻璃/木/烤盘语义。

### Western Dining
禁止默认使用：中式牌匾、川湘红金、毛笔门头、家常菜馆空间。

### Coffee / Tea
禁止默认使用：大面积传统金字、四宫格家常卖点章、重油重火、饭馆灯笼。

### Home-style Chinese
禁止默认使用：奶油粉甜品空间、过度冷感 Fine Dining、咖啡馆 lifestyle 主导导致失去锅气。

### Premium Seafood
禁止默认使用：夜市摊位、粗糙江湖招牌、廉价电商促销风。

### Retail Packaged
禁止把包装商品改成堂食菜；包装文字、Logo、形状是产品身份的一部分。

## Cross-category Transfer Allowed

允许跨品类共享：
- Hero Product / Hero Food
- 一点透视 / 对角透视
- 空间字体这一“方法”
- 遮挡
- 统一光影
- 信息层级
- 负空间
- One Big Idea

禁止跨品类直接复制：
- 字体皮肤
- 标题材质
- 空间介质
- 场景皮肤
- 配色模板
- 道具模板
- 卖点徽章模板
- 辅助文字模块样式

## Full Typography Firewall

品类匹配不只检查主标题。

主标题、副标题、Slogan、卖点、品牌信息都必须处于同一套**品类原生文字系统**内：

- 字体人格一致但层级有差异；
- 空间介质与当前品类一致；
- 材质与场景一致；
- 辅助文字不能退化成与品类无关的平面 PPT 字层。

如果只有主标题换了字体，而副标题、卖点卡、徽章仍沿用上一品类模板，视为视觉皮肤污染。

## Fail Condition

以下任意情况应重新路由或直接 FAIL：

1. 把品类名称替换掉后海报仍几乎成立；
2. 上一品类的字体/场景/徽章/材质可以原封不动套在当前品类；
3. 当前标题所使用的空间介质无法解释“为什么属于这类食品/品牌”；
4. 主标题品类匹配，但副标题和辅助信息仍明显属于另一品类模板；
5. 当前品类上限版只是上一张成功 KV 的换产品版本。
